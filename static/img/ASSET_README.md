# Image assets
- `portfolio-room.png`: generated full-room concept artwork used behind clickable hotspots.
- `profile-placeholder.svg`: replaceable avatar placeholder; visitor upload currently previews locally only.
- `icons/*.svg`: separate, editable SVG icons created for code, Python, Django and database themes.
The room artwork itself is a flattened generated image; individual furniture/objects are not separate layers. Hotspots are independent HTML elements in `templates/portfolio/home.html`.
